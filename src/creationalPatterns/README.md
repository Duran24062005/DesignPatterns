# Patrones creacionales

Resuelven la creación de objetos y desacoplan el código cliente de las clases concretas.

| Patrón | Ejemplo |
|---|---|
| Abstract Factory | [abstract-factory](abstract-factory/) |
| Builder | [builder](builder/) |
| Factory Method | [factory-method](factory-method/) |
| Prototype | [prototype](prototype/) |
| Singleton | [singleton](singleton/) |

Selecciona Abstract Factory para familias de productos, Builder para construcciones por pasos, Factory Method para delegar la instanciación, Prototype para clonar y Singleton solo cuando exista una única instancia realmente necesaria.

Referencia: [Refactoring Guru](https://refactoring.guru/design-patterns/creational-patterns).
